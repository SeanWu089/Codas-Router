# Codas for Windows — RC8 candidate

Enter the trusted HTTPS Core origin, its pairing code and an authorized workspace. The access switch starts off. Existing paired RC7 profiles retain their original origin and credentials. A separate explicit re-enrollment workflow is required to move to another Core.

This public-safe source snapshot preserves the SSE-only transport, redirect rejection, local session authorization, bundled DevSpace Lite and RC7 UI. Private build archives and history are not included. The Windows workflow performs runtime and disposable Windows installation tests before publishing a prerelease. Real-device acceptance remains separate.
